### Hypothesis

Replacing the parent FM's pointwise log-loss training with GAUC-matched within-user BPR loss, while holding the controller causal feature matrix and FM scoring form fixed, will improve within-user ordering and therefore raise primary score, with the largest effect on GAUC-eligible mixed-label users.

**Objective.** Minimize mean softplus(-(s_positive-s_negative)) over sampled within-user positive-negative pairs, plus the same form of parameter regularization used by the parent. This is the only principal scientific change; feature construction, FM score parameterization, causal cutoff, and prediction interface remain fixed.

**Mechanism.** The parent pointwise objective spends capacity calibrating independent row probabilities, including comparisons that cannot affect within-user metrics. The proposed BPR objective directly increases each observed positive-negative score margin inside an eligible user's logged slate. Sampling a positive uniformly from GAUC-eligible users and then a negative uniformly from that user's logged negatives, with the prescribed correction so each eligible pair has effective weight proportional to 1/N_u where N_u is the user's positive count, aligns expected gradient contribution with positive-count-weighted GAUC while preserving the parent's inference-time FM score.

**Principal change.** Change only the training objective and associated sampler from pointwise binary log loss to GAUC-matched within-user BPR pairwise loss for the existing FM scoring model.

**Expected metric effects.** GAUC, nDCG@5

+    """Build compact indices for positive-weighted eligible-user pair sampling."""

+    inverse = np.asarray(inverse, dtype=np.int64)

+    positive_mask = targets == 1.0

## Iteration 2 — `candidate-02-a9a20bb70fd3d44d`

### Hypothesis

Replacing the parent's pointwise binary log loss with user-slate softmax cross-entropy, while holding its score function and causal feature bundle fixed, will improve the mean of GAUC and nDCG@5 by more than 0.002 because optimization will directly compare impressions within the same user rather than spend capacity on between-user calibration.

**Objective.** Minimize the mean over included user slates of L_u=-sum_i (y_ui/P_u)*log(exp(s_ui-max_j s_uj)/sum_j exp(s_uj-max_k s_uk)), for P_u>0, plus the unchanged parent L2 regularization. This listwise objective is the sole principal scientific change from the parent's pointwise logistic loss.

**Mechanism.** For each positive-containing user slate u, compute logits s_ui from the same FM-style scorer used by the exact parent, apply a numerically stable softmax across only that user's logged impressions, and minimize -sum_i q_ui log p_ui where q_ui=y_ui/P_u and P_u=sum_i y_ui. Thus every positive row receives target mass 1/P_u. Zero-positive slates contribute no listwise gradient; all-positive slates are retained and encourage equal scores because their ideal within-user ordering is indifferent. Add only the parent's existing regularization, with no new feature domain or architecture capacity change.

**Principal change.** Change only the training objective from pointwise binary log loss to per-user slate softmax cross-entropy with positive-normalized targets; retain the exact parent score architecture, controller-engineered 33-feature input, inference path, and regularization.

## Iteration 3 — `candidate-03-945e0e37ae42338a`

### Hypothesis

Replacing the official-fm-fallback-seed-4 pointwise binary log-loss objective with positive-normalized, per-user listwise softmax cross-entropy over each user's logged impression slate will improve within-user ordering and therefore the primary mean of GAUC and nDCG@5 without increasing feature breadth or model capacity.

**Objective.** Per included user u, L_u = -sum_i (y_ui/P_u) log(exp(s_ui)/sum_j exp(s_uj)), computed with log-sum-exp stabilization and averaged across included user slates, plus the parent's L2 regularization. This is the sole principal scientific change from the exact parent; feature bundle and FM scoring capacity remain fixed.

**Mechanism.** For each positive-containing user slate, compute scores from the same FM-family scoring capacity as the parent, apply a numerically stable log-softmax across that user's existing impressions, and minimize cross-entropy against a target distribution assigning mass 1/P_u to each of the P_u positive rows and zero to negatives. This directly penalizes positive rows falling below competing logged impressions. Zero-positive slates provide no valid positive target and are excluded. All-positive slates are retained as specified, although they mainly regularize score symmetry and cannot improve GAUC. Prediction remains a row-wise finite score and requires no group information.

**Principal change.** Replace pointwise binary log loss with per-user positive-normalized listwise softmax cross-entropy over logged impression slates.

**Expected metric effects.** GAUC, nDCG@5

- Bruch et al., ICTIR 2019: softmax cross-entropy as a convex bound on NDCG and an NDCG-consistent listwise objective.
